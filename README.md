# Nekotris :3

Tetris neko em HTML/CSS/JavaScript, feito para desktop e celular.

## Rodar localmente
Abra `index.html` no navegador, ou rode:

```bash
python -m http.server 8000
```

E acesse `http://localhost:8000`.

## GitHub Pages
1. Crie um repositório e coloque `index.html`, `style.css` e `game.js` na raiz.
2. Vá em **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione `main` e `/ (root)` e salve.

## Controles
Desktop: setas, Espaço, X/↑, Z, C, P/Esc.
Mobile: botões na tela.
